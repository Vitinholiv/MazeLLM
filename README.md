# LLM Preditor de Labirintos

- Modelo inspirado no GPT-2, prevendo token a token com tamanho fixo onde o treino foi com início = superior esquerdo, fim = inferior direito, padding final.

- Visualizador de Atenção.

- Training set agora com início e fim dinâmicos.

- Modelos Encoder, Decoder e Encoder-Decoder.
